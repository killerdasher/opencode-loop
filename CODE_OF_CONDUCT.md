# Code of conduct

## Our standard

This project is a small, evidence-driven engineering tool. The working standard is simple:

- **Critique work, not people.** Review designs, code, and documentation on their merits.
- **Be precise and truthful.** Claims need evidence; uncertainty is stated, never concealed. The same honesty standard documented in `docs/design-principles.md` applies to how we treat each other.
- **Assume good faith.** The maintainers and contributors come from different backgrounds, time zones, toolchains, and skill levels; terse replies are not rude ones by default.
- **No harassment, insults, trolling, or personal attacks.** Not in issues, PRs, chats, or anywhere else this project touches.

## Scope

This standard applies to this repository's issues, pull requests, discussions, and any project-managed space, and to anyone representing the project in public communication.

## Enforcement

Maintainers may edit, hide, or delete contributions that violate this standard, and may block repeat offenders. Posts that publicly disclose a security vulnerability — endangering users (see [SECURITY.md](SECURITY.md)) — will likewise be removed and redirected to private reporting.

If you experience or witness unacceptable behavior, contact the repository owner (killerdasher) privately via GitHub direct message, or through a contact channel listed on their GitHub profile.
